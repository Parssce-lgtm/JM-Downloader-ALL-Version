# JM downloader 1.6.6 / Build 18

原生 SwiftUI / UIKit 漫画下载应用，支持 JMComic 与 PicACG，最低系统版本为 iOS 26.0。针对 iPhone 17 Pro Max 适配安全区域、自适应布局与动态字体。

- 右上角设置 → 账号设置：JMComic / PicACG 平台切换与各自登录、API 域名、HTTP CONNECT 代理、图片并发、刷新收藏、记住账号、文件目录、隐藏已完成/已删除任务。
- 顶部模块依次为下载任务 / 漫画收藏 / 漫画推荐，支持左右滑动切换。收藏支持搜索、收藏夹筛选和隐藏漫画；推荐默认最多爱心排序，支持独立搜索及 `#标签` 精确检索。
- 下载任务长按可暂停、切换自动下载和删除任务及缓存；卡片上的播放按钮继续下载。批量删除保留已经导出的 PDF。
- 设置 → 漫画设置查看已排除的漫画；设置 → 黑名单可按标签和漫画名过滤推荐。刷新收藏自动补充队列可独立开关。
- URLSession 后台图片传输、持久化队列、图片解扰、原生 PDF 输出。平台切换保留各自账号的收藏、任务与排除名单。

## 构建

先下载仓库中的 `JM-downloader-source.zip` 并解压，再用 Xcode 26 或更新版本打开 `JMDownloader.xcodeproj`，选择 `JMDownloader`。真机安装设置自己的 Development Team 与 Bundle ID。

```sh
bash scripts/test-ios.sh
bash scripts/build-unsigned-ipa.sh
```

GitHub Actions 手动执行 Build iOS，先测试再生成 `JM-downloader-unsigned.ipa`。未签名 IPA 需要自行签名后安装。默认不包含开发者证书、个人账号或个人漫画文件。


## 使用

首次进入右上角设置登录。API 域名可填多个 HTTPS 主机，以逗号分隔。代理仅支持无需认证的 HTTP CONNECT 代理（主机、端口），使用系统 Network / URLSession API；SOCKS 可由系统 VPN 提供。网络设置保存后重新登录；后台传输代理在下次启动时生效，图片域名在任务暂停再继续时更新。

默认 PDF 在“文件 → 我的 iPhone → JM downloader”。选择其他目录使用系统文件选择器与安全作用域书签；外部云盘不可用时任务显示失败并保留缓存，可重试。删除任务不会删除已导出的 PDF；可在文件 App 自行管理。

后台图片传输由 iOS 调度。应用被用户强制划掉时系统会取消传输，重新打开恢复未完成任务。章节清单准备、推荐计算及 PDF 合成需要应用获得执行时间；不承诺锁屏后永久运行。推荐统计收藏详情中的全部有效标签，检索多个标签的候选并补全详情后综合排名；没有收藏时不混入热门列表。JM 首次读取完整标签需要逐本请求；已读取标签按账号持久保存，刷新、搜索、续登及重启会复用缓存，只补读新增或缺失的标签。

服务端 API 非官方，可能随服务端升级变化。原版 jmcomic 2.7.7 的协议算法参考与 MIT 许可见 `THIRD_PARTY_NOTICES.md`。

## 更新记录

### 1.1.0

- 接入原生 PicACG 登录、收藏分页、搜索、推荐、章节下载与 PDF 导出；账号设置切换 JMComic / PicACG。
- API 可留空：自动使用内置 JM 与 PicACG 地址；代理留空走系统网络。网络受限时需使用自己的系统 VPN 或可用代理，没有通用代理地址。
- 点击输入框以外区域收起键盘，保留按钮和列表操作。
- 主题设置：跟随系统／浅色／深色；蓝、黑白、橙、粉、绿五种主题色；保留经典图标并增加四款原生可切换图标。
- 兼容 1.0 本地任务、收藏与设置；密码仍由设备 Keychain 保存，公开源码及 IPA 不预置个人账号。

### 1.2.0

- 账号设置右上角“保存”：确认设置写入设备存储成功后关闭整个设置页；失败保留页面并提示，不再仅播放反馈。
- “保存线路设置”：保留当前页面，显示保存结果并触发原生成功／失败触觉反馈。新增恢复默认线路及无需凭据的 API 连通检测。
- API 留空时保存为实际默认地址；线路检测只验证网络可达，不能代表登录或下载成功。
- 网络错误区分离线／权限、DNS、超时、TLS、服务器不可达，并附错误码及主机名，不记录密码、令牌或请求路径。
- 主题页明确继承当前主题，采用普通按钮样式与语义前景色，避免未选择时出现系统默认蓝色。

### 1.2.1

- 修正错误 -3000 的诊断：这是 iOS 无法创建下载文件，不是 API 或 VPN 连接错误。
- 系统后台下载临时文件创建失败时，自动切换原生 URLSession 数据流，将图片分块写入应用内部缓存，避免依赖同一临时下载机制；内存缓冲为 64 KiB。
- 标准后台传输仍保留。兼容下载受系统后台执行时间限制，建议保持应用打开；到时自动暂停，保留已完成图片，可继续。
- 所有图片下载、解扰和 PDF 转换均在应用内部进行。PDF 页数校验成功后，才通过文件协调器复制至“文件”目标目录，不在目标目录边下载边转换。
- 取消或失败会清理未完成的数据流文件；旧任务回调不会覆盖新任务图片。

### 1.4.0

- 点击书架中的下载按钮立即显示转圈，排队、下载和生成 PDF 期间持续反馈，完成后显示对号。

- 下载任务页用任务标题、数量、全部开始/暂停替换书架工具栏；任务多选与删除保留在任务操作按钮中。
- 漫画收藏和推荐默认隐藏已下载项，更多中的“查看已下载”可展开，再点“隐藏已下载”可收起。
- 登录、重开恢复会话和切换平台后自动加载推荐；后台加载失败只写入记录，不弹窗打断启动。
- 推荐增加最新、最多爱心、最多点击、最多查看；使用服务端排序，按推荐主题依次合并去重。两服务只有同一浏览量排行，因此点击和查看使用同一个指标。
- PicACG 适配 static/static、tobeimg 转换图、tobs 原图等媒体路径；图片服务器拒绝时按协议内已知 CDN 有限切换。封面和两种下载模式使用相同请求规则，不向图片服务器发送账号凭据，不改写自定义域名。
- JM 已登录会话的首选域名超时后可尝试备用域名，单条线路请求超时 10 秒；备用后端重新建立会话，不转发旧 Cookie。所有线路不可用时保留真实失败信息，不保证绕过服务端故障或设备网络限制。
- 重装后若钥匙串保留登录信息，可找回当前平台账号并刷新空书架。
- 不再创建 BGContinuedProcessingTask 或灵动岛进度，清理旧版尚未执行的持续后台请求。图片通过 URLSession 后台下载；PDF/兼容下载通过有限后台执行时间和 BGProcessingTask 接续，不保证离开应用后立即完成。强制退出仍受 iOS 限制。旧版已显示的系统活动可能需要手动关闭。
- 图片及 PDF 转换仍全部在应用内完成，最终验证通过才放入文件 App。

### 1.5.0

- 修复 JM 章节解扰参数格式变化：兼容带引号、冒号、下划线/连字符的 `scramble_id` 返回；服务未提供参数时按原图继续下载，不再因为单个 HTML 变体直接停止整本任务。JM 与 PicACG 下载并发按平台隔离，暂停的 PicACG 任务不会占满 JM 的图片槽位。
- 漫画设置下新增标签黑名单。逗号分隔、支持模糊匹配；只过滤漫画推荐，不影响收藏和搜索。

- PDF 生成只读取应用私有缓存中的已下载图片，不发送网络请求；下载完成后可离线生成 PDF。发布到外部下载目录仍可能受目录提供方授权影响。
- 收藏、推荐和下载任务的封面支持双击放大预览，显示标题、平台编号、标签和来源信息。

### 1.6.4

- **收藏加载**：显示“正在加载”，使用独立的托盘图标；“这里还没有漫画”的原有图标保持不变。
- **推荐提示**：加载时显示“正在搜索…”和循环搜索图标；网络连接、登录会话或接口失败时显示“网络已断开”，不增加重试按钮。有漫画显示后，中央加载图标和提示隐藏。
- **独立进度记录**：收藏和推荐底部各有不可打开的“提示记录”，显示处理阶段、已处理数量与百分比。与下载任务的日志相互独立；下载页提示记录仍可打开。
- **推荐加载**：逐项展示已核验的推荐漫画，继续统计全部有效收藏标签，保留黑名单和已下载过滤。部分标签检索失败时继续使用其他有效结果；全部失败或会话过期会明确报错。主动搜索保持独立。
- **PDF 合成**：图片下载阶段继续显示 `xx / xx 张`；生成 PDF 时改为实际处理百分比，进度条重置并从右向左填充。文件校验与保存完成前最高显示 99%。
- **底部布局**：调整收藏、推荐的列表和安全区，末尾留出空间，使最后一张漫画卡片可以完整显示、点击。键盘出现时提示记录不会上移遮挡搜索按钮，保留左右滑动切换模块。
- **浅色外观**：收藏、推荐、下载页的提示记录统一增加清晰底色、细边框和轻微阴影，改善胶囊边界的辨识度。

推荐进度按收藏标签处理（0–40%）、标签检索（40–55%）、候选详情核验（55–99%）计算，整体成功后为 100%。收藏进度按当前已知分页处理量计算，发现新收藏夹时总量可能增加；百分比表示处理数量，不是网络传输量或剩余时间。
API 资源超时为 30 秒，收藏和推荐单轮加载上限为 180 秒，主动搜索为 60 秒；会话续登后可再请求一轮。故障线路会短暂降低优先级，失败信息显示在对应页面的提示记录中。已有漫画保留，重新加载可使用下拉刷新或更多菜单。

### 1.6.6

- **Build 18：推荐与缓存**：JM 完整标签逐本持久保存，重启、续登、刷新与搜索不再丢失已读取标签；新增收藏只补读缺失数据。详情请求保持有界并发，先展示首个有效结果，再分批更新大量推荐卡片；缓存和网络读取不占用主线程。

- **状态与布局**：网络超时等传输故障显示“网络已断开”；会话过期、无有效推荐及数据错误显示带独立图标的“加载失败”。搜索圆环扩大留白。三页卡片统一封面、内边距和基础高度；收藏和推荐的底部提示去掉“提示记录”标题，文本居中并使用更透明的玻璃。点击顶部 JM downloader 返回当前列表顶部。
